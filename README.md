# Exploratory Data Analysis & Dark-Mode Dashboard in Python

## 📌 Overview
This repository contains a full **Data Analysis and Visualization project** executed in Jupyter Notebook. The goal is to clean raw business datasets, compute key metrics, and present visual insights through custom dark-mode charts.

## 🛠️ Tools & Libraries
* **Language:** Python 3
* **Environment:** Jupyter Notebook (`.ipynb`)
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn

## 🔍 Key Deliverables
* **Data Cleaning:** Outlier detection, missing value handling, and proper type formatting.
* **Exploratory Data Analysis (EDA):** Statistical summaries and distribution checks.
* **Visual Dashboards:** Executive-ready dark-mode visualizations ready for presentation.
